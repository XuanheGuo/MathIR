# Matherium Algebraic Step Verifier

The provider exposes `mathir.verify-algebraic-step@0.1.0` synchronously and deterministically over
Matherium Protocol `0.2.0`. The provider service version is `0.4.0`; the MathIR document version
remains `0.1.0`.

The strict input wrapper requires all four fields:

```json
{
  "document": {},
  "stepId": "step-id",
  "verificationMode": "auto",
  "conditionMode": "ignore"
}
```

`document` accepts any JSON value so invalid MathIR can return the domain outcome
`invalid_document`. Domain outcomes `verified`, `conditionally_verified`, `rejected`, `unknown`,
and `invalid_document` all produce HTTP 200 and a succeeded Invocation. Only malformed wrappers,
protocol failures, unknown capabilities, and sanitized internal errors are exchange failures.

The manifest includes three outputs generated by the real execute function: a polynomial identity,
a conditional rational cancellation, and the same rewrite discharged by a step-declared nonzero
condition. Inputs and outputs are checked against strict Zod and Draft 2020-12 JSON Schemas and are
byte-identical across repeated execution. Provider output remains within the 900 KiB JSON budget.
